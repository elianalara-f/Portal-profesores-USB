# Portal Docente - USB Cartagena

Proyecto web interactivo desarrollado para la gestión de horarios, asignaturas y perfil docente de la Universidad de San Buenaventura Cartagena. Diseñado con maquetación semántica HTML5, estilos adaptativos CSS3 y dinámicas interactivas en JavaScript.

## Características y Funcionalidades

* **Navegación Interna Fluida**: Menú interactivo con desplazamiento suave (`scroll-behavior`) a las secciones principales.
* **Maquetación Semántica**: Uso de etiquetas nativas (`header`, `nav`, `main`, `section`, `aside`, `footer`).
* **Diseño Adaptativo (Responsive)**: Estructura responsiva construida con Flexbox y CSS Grid.
* **Componentes Dinámicos (JavaScript)**:
  * Sistema de cierre de sesión mediante manipulación de eventos (`addEventListener`).
  * Ventana modal para notificaciones y mensajes emergentes.
  * Validación visual de formularios.
